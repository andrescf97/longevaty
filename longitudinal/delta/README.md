# Delta Model Documentation

This directory contains the implementation of the **Delta Model**, a longitudinal deep learning approach designed to predict lung cancer risk by explicitly modeling the *trajectory of change* between consecutive LDCT scans.

Unlike standard models that process sequences of static images (e.g., RNNs or LSTMs), the Delta Model computes "velocity vectors" (deltas) between timepoints and uses an attention mechanism to weigh their importance against the most recent scan.

## Quick Start: Training & Inference

### 1. Training the Model

To train the Delta Model, execute the training script from the project root. This pipeline handles dataset initialization, class balancing, and distributed logging via WandB.

```bash
python adlm_lft/longitudinal/delta/train_delta.py

```

**Configuration (`adlm_lft/configs/train_delta.yaml`)**
The training pipeline is managed via **Hydra**. Ensure the following critical parameters are set before launching:

* **Data Paths:**
* `features_train` / `features_dev`: Path to `.pt` feature files generated by the Feature Extractor.
* `json_train` / `json_dev`: Path to MONAI dataset JSON metadata.


* **Balancing Strategy:**
* `augment_train`: Set to `True` to enable random subsequence sampling.
* `oversample_max_repetition`: Controls class balancing. Set to `1` to disable, or `>1` (e.g., `10`) to oversample rare cancer years to match the majority class.


* **Loss Weights:**
* `lambda_mean`: Controls the penalty for regression error (predicting the exact year).
* `lambda_var`: Controls the penalty for prediction uncertainty (variance).



**Training Pipeline Overview:**

1. **Initialization:** Loads patient sequences and applies dynamic oversampling if enabled.
2. **Optimization:** Computes the hybrid **Ordinal Loss** (BCE + Mean-Variance) to optimize for both risk (binary) and timing (regression).
3. **Checkpointing:** Monitors validation AUPRC. The best model state is saved to `best_delta_model.pt` when early stopping criteria are met.

### 2. Inference & Evaluation

To evaluate a trained model on the test set and generate prediction artifacts:

```bash
python adlm_lft/longitudinal/delta/test_delta.py

```

**Configuration (`adlm_lft/configs/test_delta.yaml`)**

* **Checkpoint Path:** Must point to a valid `.pt` model file.
* **Architecture Consistency:** Parameters like `input_dim`, `hidden_dim`, and `num_heads` must match the configuration used during training.

**Outputs:**

* **Metrics:** Logs Global AUC, AUPRC, C-Index, and time-dependent AUCs (e.g., AUC @ 1 Year) to WandB.
* **Artifacts:** Saves `test_predictions.csv` containing patient-level risk scores, predicted years, and ground truth labels.

## Technical Implementation

### 1. Longitudinal Dataset Generation

*Source: `adlm_lft/longitudinal/delta/dataset.py*`

The dataset class transforms independent scans into patient-specific sequences.

* **Data Aggregation:** Scans are grouped by Patient ID (`pid`) and sorted chronologically (). Features are loaded from a dictionary mapping (`{exam_id: tensor}`) to ensure  lookup speeds.
* **Padding Strategy:** If a patient has fewer scans than `max_seq_len` (default: 3), the sequence is padded by **repeating the last scan**.
* *Why?* Since the model learns from *changes* (deltas), repeating a scan creates a "zero-velocity" vector, effectively telling the model "no change occurred" rather than introducing synthetic noise.


* **Augmentation:** During training, `random.sample` is used to pick subsequences (e.g., skipping  to see the jump from ). This teaches the model to handle varying time intervals.

### 2. Delta Model Architecture

*Source: `adlm_lft/longitudinal/delta/model.py*`

The model explicitly computes the dynamics of disease progression rather than relying on recurrent states.

1. **Feature Projection:** Input embeddings (dim: 1584) are projected into a shared latent space (dim: 256) via an MLP.
2. **Explicit Delta Calculation:**
* **Recent Velocity:**  (Immediate change).
* **Historical Velocity:**  (Long-term trend).


3. **Attention Mechanism:** A Multi-Head Attention layer fuses these signals:
* **Query ():** The current scan ().
* **Key/Value ():** The delta vectors.
* *Intuition:* "Given the current scan, which past changes are most relevant for predicting future risk?"


4. **Fusion:** The context vector from attention is concatenated with the current scan embedding to produce the final logits.

### 3. Ordinal Loss (Hybrid Objective)

*Source: `adlm_lft/longitudinal/delta/loss.py*`

The problem requires determining **if** a patient will get cancer (Binary) and **when** (Ordinal). Standard Cross-Entropy treats "Year 1" vs "Year 5" errors equally, which is clinically undesirable. We use a custom **Mean-Variance Loss**:

* **Risk Component (BCE):**
. This sums the probability mass of all cancer years and optimizes it against the binary label (Healthy/Cancer).
* **Mean Loss (Accuracy):**
For positive cases, we re-normalize the cancer probabilities to sum to 1.0. We then calculate the **Expected Year** (weighted average) and minimize the MSE against the true diagnosis year.
* **Variance Loss (Precision):**
We penalize the variance of the predicted time distribution to discourage "hedging" (assigning low probability to all years).
